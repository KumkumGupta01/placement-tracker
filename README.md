
# Placement Tracker 🎯

A full-stack web application designed to track college placement and internship applications, interview rounds, CTC packages, and application statuses in real time.

## 🚀 Tech Stack

- **Frontend:** React, Vite, Lucide Icons, Pure CSS
- **Backend:** Node.js, Express.js, REST API Architecture
- **Version Control:** Git, GitHub

## 📌 Features

- **Application Metrics:** Live counts for total applications, active interview rounds, and offers received.
- **RESTful Endpoints:** Full CRUD support to add, view, update, and delete company records.
- **Interactive Pipeline:** Categorized status badges (`Applied`, `OA Scheduled`, `Interview Round`, `Offer Received`, `Rejected`).
